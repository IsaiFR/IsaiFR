## Proyectos

### [Didacteca Generator](https://github.com/IsaiFR/Didacteca-Generator)

API educativa en **Python y FastAPI** que integra OpenAI con el Context Service de Didacteca para responder preguntas, generar quizzes y preparar actividades a partir de una sección de referencia.

El proyecto incluye contratos y validaciones explícitas, manejo de errores de proveedores, límites de recursos, tratamiento de fórmulas en LaTeX, pruebas automatizadas y un workflow de CI para Windows y Ubuntu. El repositorio documenta la arquitectura, la evidencia de las verificaciones y las limitaciones de la solución.

[Documentación](https://github.com/IsaiFR/Didacteca-Generator#readme) · [Código](https://github.com/IsaiFR/Didacteca-Generator) · [CI](https://github.com/IsaiFR/Didacteca-Generator/actions)

También gestiono información estudiantil y elaboro recursos didácticos.
